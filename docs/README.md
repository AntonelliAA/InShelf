# InShelf Docs

| Document | Read it when |
|---|---|
| [architecture.md](architecture.md) | Changing data flow, adding a screen, or touching persistence |
| [known-issues.md](known-issues.md) | Before fixing anything — it may already be catalogued with a file:line |
| [roadmap.md](roadmap.md) | Before proposing a feature — most gaps are already sequenced |
| [agents.md](agents.md) | Delegating work to AI agents, or updating the context layer |
| [git-conventions.md](git-conventions.md) | Writing a commit, naming a branch, or opening a PR |

Agent-facing instructions (commands, conventions, boundaries) live in [../AGENTS.md](../AGENTS.md) at the repo root, where every AI coding tool looks for them. Human-facing project overview is in [../README.md](../README.md).

These files describe the code as it is, not as it should be. When they disagree with the source, the source is right and the doc is a bug.
